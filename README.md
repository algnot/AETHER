# Aether Duel

เกมการ์ดออนไลน์แนว Master Duel (เฟสแรก: vs CPU + จัดเด็ค)

## รันโปรเจกต์

ต้องการ MongoDB ที่ `mongodb://127.0.0.1:27017` (ดู `.env.example`)

```bash
npm install
cp .env.example .env.local   # ครั้งแรก
npm run dev
```

เปิด http://localhost:3000 — frontend + API (`/api/*`) อยู่โปรเจกต์ Next.js เดียวกัน

## กติกาหลัก (เฟสนี้)

- การ์ด: มอนสเตอร์ / เวทย์มนต์ (ชาร์จพลังงาน) / กับดัก (โล่แห่งแสง)
- มอนสเตอร์มีเผ่า · ATK · ค่าร่าย — ยังไม่มีเอฟเฟค
- HP เริ่ม 20 · พลังงาน: ฝ่ายแรกได้ 3 · ทุกเทิร์น +2 · ยกยอดได้สูงสุด 3
- Phase: Draw → Main → Battle → Main 2 → End
- มอนสเตอร์ที่เพิ่งลงโจมตีไม่ได้ · ฝ่ายแรกโจมตีไม่ได้ในเทิร์นแรก
- เด็ค 40–50 ใบ · การ์ดซ้ำได้สูงสุด 3 ใบ
